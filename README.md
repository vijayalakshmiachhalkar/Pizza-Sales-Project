This dashboard provides a complete 360° view of sales performance, helping stakeholders understand trends, customer behavior, and product performance.

🔍 Project Objective
To analyze pizza sales data and identify:
• Revenue drivers
• Customer ordering patterns
• Best & worst-performing products
• Time-based sales trends

🛠️ Tools & Technologies
• SQL (MySQL) → Data extraction, cleaning, and aggregation
• Microsoft Excel → Dashboard design, charts, and interactivity

📊 Key KPIs (From Dashboard)
• 💰 Total Revenue: $817,860
• 📦 Total Orders: 21,350
• 🍕 Total Pizzas Sold: 49,574
• 📈 Avg Order Value: $38.31
• 🔢 Avg Pizzas per Order: 2.32

📌 SQL Analysis Highlights
✔ Used GROUP BY & JOINs to calculate category & size-wise sales
✔ Identified Top 5 Best & Worst Sellers using ranking queries
✔ Extracted daily & hourly trends to find peak business hours
✔ Calculated KPIs like revenue, AOV, and total orders using aggregate functions
✔ Performed time-based analysis using DATE functions

📈 Dashboard Insights (Excel Visualization)
🔥 Sales Trends
• Highest orders on Friday (3538) → weekend demand spike
• Strong performance on Thursday & Saturday
• Lowest on Sunday → potential opportunity

⏰ Peak Hours
• Maximum orders between 12 PM – 4 PM
• Indicates lunch & early evening demand

📦 Size Analysis
• Large pizzas generate ~46% of revenue
• Medium size contributes ~30%
→ Larger pizzas are the primary revenue drivers

💡 Business Insights
• Focus marketing on weekend & peak hours
• Promote large-size pizzas for higher revenue
• Improve or remove low-performing products
• Bundle offers can increase average order value

🚀 What I Learned
• Converting raw data into business insights using SQL
• Designing interactive dashboards in Excel
• Understanding real-world business metrics
• Data storytelling for decision-making
